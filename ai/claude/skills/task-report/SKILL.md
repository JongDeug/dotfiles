## 원칙

- **보고와 기록을 나눈다.** `보고.md` = 읽는 사람이 상태 · 남은 일 · 정할 것을 몇 초에 보는 것. 목표 · 메모 · 정리 · raw = 기록. 경위 · 근거 · 대안 · 실측을 붙이지 않는다
- **챕터 = `하위/{하위 작업}/` 폴더 = 노션 하위 작업.** 지금 하는 것 · 바로 다음 것 정도로 굵게
- **쓰는 곳은 `보고.md` 와 하위 `목표.md` frontmatter(`단계` · 날짜 · 노션)뿐.** 나머지는 읽기만. 쓰기 직전에 다시 읽는다

## 챕터 양식 — 네 블록

```markdown
## {하위 작업 이름}
(무엇을 · 왜 — 한 줄. 하위 목표.md 「하려는 것」)

**레포**
- {레포} `{브랜치}` — 한 일 (커밋 전 · develop 머지 · master 머지)

- [x] 끝난 일 — 핵심 결과 (MM-DD)
- [ ] 남은 일 …
- [ ] MR · 배포

정할 것 — … (있을 때만)
```

- 상태 · 담당 · 날짜는 하위 `목표.md` frontmatter 가 원본 — 본문에 「지금」 줄을 쓰지 않는다. 할 일 체크가 진행 상황이다
- **레포** 는 코드가 생긴 뒤에만. 레포 없는 설정 파일은 경로로(예: 상자 `/etc/haproxy/haproxy.cfg`). 머지 상태는 git 으로 확인한 값만
- 할 일 = 하위 `목표.md` 「다 됐다고 보는 기준」 + 그 하위의 메모 · 정리에 있는 열린 체크박스(원래 자리는 그대로). 마지막은 MR · 배포
- 챕터 이름에 작업명 · 요구사항 번호를 붙이지 않는다

`보고.md` 맨 위: frontmatter `갱신: YYYY-MM-DD` · `# {작업} — 보고` · 2줄(한 줄 정의 · **지금**). 그 아래 챕터들.

## 뽑기 — 먼저 대화로 보고, 쓰는 건 시킬 때만

1. 읽는다 — 상위 `목표.md` · `메모/` · `정리/` · `raw/`, 그리고 `하위/*/` 마다 `목표.md` · `메모/` · `정리/` · `raw/`(PDF · 이미지 포함). `보고.md` 가 있으면 `갱신` 뒤로 바뀐 파일(mtime)부터
2. 챕터 = 지금 있는 `하위/` 폴더들. 새 하위 작업이 보이면 「더할 안」으로 따로 적는다(폴더는 task-new 가 만든다). 하위가 하나도 없으면 챕터 안을 표로 제안한다
3. 노트끼리 어긋나는 사실은 고치지 말고 그 챕터의 **정할 것** 에 올린다
4. **대화로 보고한다** — 맨 위 2줄 → 표 `챕터 | 단계 | 지금 | 정할 것`(한 칸 한 줄) → 챕터마다 근거 노트 한 줄 → `보고.md` 가 있으면 달라진 챕터만 표시 → 끝에 「이대로 `보고.md` 에 쓸까요?」
5. 「써줘」 · 「반영해줘」 · 「이대로」 면 그때 `보고.md` 를 쓰고, 하위 `목표.md` 의 `단계` · 날짜를 맞춘다(할 일이 다 체크됐으면 `완료` 는 제안만 하고 묻는다)

### 공유용 한 장

「공유용으로 뽑아줘」 면 `보고.md` 를 바탕으로 대화에 낸다 — 맨 위 2줄 + 표(`하위 작업 | 단계 | 지금 | 정할 것`). 메일 · 메신저에 붙일 수 있게.

## 노션 동기화 (시킬 때만)

1. notion-ticket 스킬을 같이 읽는다(DB 좌표 · 속성 · 쓰기 전 재조회)
2. 상위 `목표.md` `노션:` = 노션 작업. `하위/{이름}/목표.md` `노션:` = 노션 하위 작업. 비었으면 이름 그대로 하위 작업을 만들고(상위 작업 관계 · 담당자 · 상태 · 시작일) URL 을 채운다
3. 상태는 `단계` 를 바꿔 보낸다: 준비 → 시작 전 · 진행 · 배포 → 진행 중 · 완료 → 완료 · 보류 → 보류. 날짜는 그대로
4. 노션 하위 작업 본문 = 그 챕터(네 블록) 그대로. 노션 작업 본문은 건드리지 않는다(시키면 `보고.md` 맨 위 2줄)
5. 노션의 상태 · 날짜가 옵시디언과 다르면(사람이 노션에서 바꿈) 덮어쓰기 전에 차이를 보여 주고 묻는다

## 하지 않는 것

- 「뽑아줘」만 듣고 `보고.md` 쓰기 — 보고 먼저, 쓰기는 「써줘」 뒤
- 목표 본문 · 메모 · 정리 · raw 고쳐 쓰기 · 지우기 · 옮기기
- 챕터에 경위 · 대안 · 실측 붙이기, 「지금」 줄 쓰기
- 시키지 않은 노션 쓰기
