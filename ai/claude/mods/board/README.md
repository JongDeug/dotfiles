# board

입력창 바로 위 두 줄 계기판. statusline 을 대신한다.

```
 ◆ Opus 5.5  high   ~/…/com.m1ucs/detector   ⎇ develop ↑1   ● 3 +48 −12   CI ✓ build · 3분 전        ⠹ 1m12s  Bash  도구 8  편집 2
 CTX  37%  ███▆▆▆▆▆▆░░░░░┃░░░░  371k/1M ▁▂▃▅   5H ▰▰▱▱▱▱▱▱ 25% ⟲2h22m   7D ▰▰▰▱▱▱▱▱ 37% ⟲3d3h   $77.56  🔥 $9.8/h
```

- **윗줄 — 어디서 무엇을**: 모델·effort, 경로, 브랜치(↑↓), 바뀐 파일 수와 +/− 줄, CI(GitHub `gh` · GitLab `glab`, 현재 브랜치 마지막 실행). 오른쪽 끝은 도는 동안 스피너·경과·지금 도구·도구/편집/에이전트 수, 끝나면 `지난 턴 …`.
- **아랫줄 — 얼마나 남았나**: 컨텍스트를 `/context` 분류별 색으로 쌓은 막대(`┃` 자동 압축 자리, `▁▂▃▅` 턴마다 % 추이), 5시간·7일 사용량 한도와 초기화까지 남은 시간, 비용과 시간당 소모율. 50%·80% 에서 초록 → 노랑 → 빨강.
- **포인터를 올리면** — 변경 알약 위에 파일 목록, CTX 위에 분류별 토큰 수가 펼쳐진다.
- 갱신: 도는 동안 0.25초(스피너), 컨텍스트·한도 5초, git 10초(명령·편집이 끝날 때도), CI 1분.

값은 `$.session.usage({ breakdown: 'summary' })`(statusline 이 받는 것과 같은 숫자 + /context 분류), `$.session.model()`, git·gh·glab 에서 온다. effort 는 훅에 오지 않아서 설정 파일의 `effortLevel` 을 읽는다.
